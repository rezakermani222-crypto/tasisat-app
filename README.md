# اپلیکیشن تاسیسات — ثبت سفارش + بانک خطای پکیج دیواری

این برنامه روی **GitHub Pages** به‌صورت رایگان اجرا می‌شود. راهنمای کامل راه‌اندازی در فایل «راهنمای راه‌اندازی گیت‌هاب» (PDF) آمده است.

## فایل‌های مهم

| فایل | توضیح |
| --- | --- |
| `config.js` | تنها فایلی که باید ویرایش کنید: نام، شماره، رمز مدیریت، مخزن سفارش‌ها و توکن گیت‌هاب |
| `index.html` | صفحه مشتری (کاتالوگ، بانک خطا، راهنما، فرم سفارش) |
| `admin.html` | پنل مدیریت سفارش‌ها (با رمز) |
| `data/errors.js` | بانک خطای پکیج‌ها — قابل ویرایش برای افزودن کدهای جدید |
| `data/boilers.js` | کاتالوگ انواع پکیج و برندها |
| `data/guides.js` | راهنماهای آموزشی |
| `assets/img/` | تصاویر — می‌توانید با عکس‌های خودتان عوض کنید |

## ذخیره سفارش‌ها

- اگر `ordersRepo` و `githubToken` در `config.js` تنظیم شده باشند: هر سفارش به‌صورت یک فایل JSON در پوشه `data/orders` مخزن خصوصی شما ذخیره می‌شود و مدیر در `admin.html` آن را می‌بیند و وضعیت می‌دهد.
- اگر تنظیم نشده باشند: سفارش به‌صورت ایمیل به `adminEmail` ارسال می‌شود.

## اعلان فوری در پیام‌رسان بله

- با بات `@tasisatrozbot` هر سفارش جدید به‌صورت یک پیام فوری در بله به چت شما ارسال می‌شود؛ حتی وقتی توکن گیت‌هاب تنظیم نشده و سفارش با ایمیل می‌رود، اعلان بله همچنان کار می‌کند.
- برای فعال شدن آن دو مقدار در `config.js` لازم است:
  1. `baleBotToken` — توکن بات (از پیش تنظیم شده است)
  2. `baleChatId` — شناسه عددی چت شما در بله؛ در بله به بات خودتان یک پیام بدهید تا شناسه را بگیرید و اینجا بنویسید.
- دکمه «گفتگو در بله» در سایت با `baleUsername` کنترل می‌شود و مشتری را به چت بات می‌برد.

## نکته امنیتی

توکن گیت‌هاب را فقط با دسترسی Fine-grained و فقط برای مخزن سفارش‌ها بسازید (نه مخزن سایت). اگر توکن لو رفت، از گیت‌هاب توکن جدید بسازید و در `config.js` جایگزین کنید.
